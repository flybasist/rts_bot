# Быстрый старт

Бот закрыт и не поддерживается; запускать его имеет смысл только из любопытства или чтобы посмотреть, как он работал.
Для настоящего использования берите [BMFT](https://github.com/flybasist/bmft).

## 1. Требования

- Python 3 (проект писался и работал на Python 3.x; точная версия не зафиксирована)
- токен бота: напишите [@BotFather](https://t.me/BotFather) команду `/newbot`
- чат, где бот состоит администратором (чтобы удалять сообщения и видеть все сообщения)

## 2. Установка

```bash
pip install pyTelegramBotAPI PyYAML schedule
cp settings_example.yaml settings.yaml
```

Версии пакетов не зафиксированы: проект писался под те, что были в 2023–2024 годах. Если новая версия
`pyTelegramBotAPI` ведёт себя иначе, попробуйте установить версию 4.x.

## 3. Настройки

Файл `settings.yaml` (в git не хранится):

| Ключ | Значение |
|---|---|
| `typedb` | `sqlite` (другие значения в коде не реализованы) |
| `idbot` | токен бота от BotFather |
| `chatforpostal` | номера чатов через запятую; в них по будням в 9:00 уходят стикеры (можно оставить заглушку, тогда отправка не удастся) |

Стикеры по будням заданы в `scheduletask.py` идентификаторами файлов автора; чужому боту они могут не подойти.

## 4. Запуск

```bash
python3 ./bot.py
```

При первом сообщении в чате бот создаёт в `rtsbot.db` три таблицы этого чата: сообщения, лимиты и реакции.
Пока ничего не настроено, все лимиты равны `0` (разрешено), а реакций нет.

## 5. Настройка лимитов и реакций

Интерфейса нет: настройка делается прямо в базе. Таблицы называются по номеру чата (например, `-1001234567890`).

```bash
sqlite3 rtsbot.db
```

```sql
-- не больше 5 стикеров в сутки для всех участников чата
UPDATE '-1001234567890_limits' SET sticker = 5 WHERE user_id = 'allmembers';

-- полностью запретить голосовые (-1)
UPDATE '-1001234567890_limits' SET voice = -1 WHERE user_id = 'allmembers';

-- VIP: лимиты на человека не действуют (поставить vip = 100 в его строке)
INSERT INTO '-1001234567890_limits' (user_id, vip) VALUES ('123456789', 100);

-- реакция: на слово «привет» отвечать текстом (для всех, на тип сообщения text)
INSERT INTO '-1001234567890_reaction' (user_id, contenttype, answertype, regex, answer, violation)
VALUES ('allmembers', 'text', 'text', 'привет', 'Здорово!', 10);
```

Столбцы реакции: `answertype` — `text` или `sticker` (в `answer` тогда идентификатор стикера), `regex` — регулярное выражение
(ищется в тексте или подписи без учёта регистра), `violation` — число-метка: по ней бот не отвечает на эту реакцию чаще раза в час.
Метка `21` особая: это «текстовые нарушения» с суточным лимитом из столбца `violation` строки `_limits`.

Важно: если у человека есть своя строка в `<чат>_limits`, **вся** она заменяет общую (незаполненные значения `0` значат
«разрешено», общие лимиты для него не действуют). Эту особенность исправили только в BMFT.

## 6. Команды бота

| Команда | Что делает |
|---|---|
| `/statistics` | Сколько человек потратил из своих лимитов за сутки (не чаще раза в час) |
| `/version` | Версия бота (не чаще раза в час) |

## Частые проблемы

| Симптом | Что проверить |
|---|---|
| Бот не удаляет сообщения | он администратор чата с правом удалять сообщения |
| Бот молчит | токен в `settings.yaml`; в `log/` смотрите файл за сегодня |
| `ModuleNotFoundError` | установлены ли `pyTelegramBotAPI`, `PyYAML`, `schedule` |
| Стикеры по будням не приходят | номера чатов в `chatforpostal`, идентификаторы стикеров |
