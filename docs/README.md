## Для ИИ-агентов и разработчиков

Эта страница — точка входа. Читайте её первой, затем нужный файл из оглавления.
Не сканируйте весь репозиторий заново: карта ниже достаточна.

### Что где лежит

| Файл | Назначение |
|---|---|
| `bot.py` | Точка входа, вызывает `telegrambot.runbot()`. |
| `telegrambot.py` | Обработчики сообщений Telegram, два потока: опрос Telegram и расписание. |
| `reaction.py` | Реакции бота: приветствия, проверка лимитов, тексты `/version` и `/statistics`. |
| `checkmessage.py` | Проверка текста по регулярным выражениям (запрещённые слова, автоответы). |
| `db.py` | Вся работа с SQLite: создание таблиц чата, подсчёты, запись сообщений. |
| `variables.py` | Сбор данных о сообщении и границ времени в один словарь. |
| `userstatistics.py` | Подсчёт «сколько человек потратил за сутки». |
| `scheduletask.py` | Стикеры по будням в 9:00. |
| `settings.py`, `settings_example.yaml` | Чтение настроек (`settings.yaml`, не хранится в git). |
| `logs.py` | Настройка логов (папка `log/`, хранение 30 дней). |
| `README.md`, `CHANGELOG.md`, `docs/` | Описание проекта и история. |

### Условия, которые нельзя нарушать

1. **Проект заморожен.** Код не меняется: это память о первом боте. Исключение — только правка документации.
2. Рабочие данные (`settings.yaml`, `rtsbot.db`, `log/`) в git не попадают (см. `.gitignore`).
3. Любые новые идеи реализуются в [BMFT](https://github.com/flybasist/bmft), а не здесь.

### Правила работы над проектом

- Комментарии в коде и вся документация — на русском. Всё, что программа печатает в
  терминал (сообщения, логи, ошибки), — на английском. (Старый код этому правилу не следует: он написан до него.)
- После любого изменения сверьте с кодом `README.md` и `docs/`: они должны описывать текущее состояние.
- Коммиты и отправку в git делает только владелец проекта.
